# CPI Inflation Analysis Using Microsoft Excel

## Project Overview
This project uses Microsoft Excel to analyze Consumer Price Index (CPI) inflation trends before and after the COVID-19 pandemic across different product categories.

## Tools & Technologies
- Microsoft Excel
- Data Cleaning and Preparation
- Data Analysis
- Data Visualization

## Project Objectives
- Analyze CPI inflation trends across product categories.
- Compare inflation patterns before and after COVID-19.
- Identify differences in inflation trends across categories.
- Present findings to support data-driven interpretation.

## Project File
- `2655C210.xlsx` — Excel workbook containing the analysis.
